app.use(express.static("public"));

app.get("/about", (req, res) => {
  res.send("About page");
});

app.use((req, res) => {
  res.status(404).send("Not found");
});

GET /images/logo.png → static middleware serves file.

GET /about → static middleware doesn’t find file → Express moves to next → route matches → sends "About page".

GET /something-else → static fails → no route matches → 404 handler responds.
